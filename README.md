# Turok-2-Poptracker
[Poptracker](https://github.com/black-sliver/PopTracker/) pack for Turok 2 (Nightdive PC Remaster) with AP support.

Tested with **Poptracker v0.35.4**, so it's recommended to use least this version.

## Usage
1. Download [Poptracker](https://github.com/black-sliver/PopTracker/).
2. Place this pack inside the _"Packs"_ folder (no need to unzip it).
3. Run **poptracker.exe** and click the folder in the upper left. Select "Turok 2 Tracker" and the desired layout.
4. To use the autotracker, click the _"AP"_ button on the top bar and enter the connection info to connect:
  - The Archipelago host and port is typically **archipelago.gg:#####**, where **#####** is the room's port
  - The slot name is the name you entered in your game's yaml
  - If there's a password, enter it here (leave it blank if there isn't one)
5. Settings will be auto-filled by default, but you can modify them manually by clicking the settings button (to the left of the _"AP"_ button).
